# Floof Database

A database for petals, mobs, and even a DPS simulation.

## Files

- **`index.html`** - the main file. Host it or open it locally.
- **`petals.json`** — every petal's stats and abilities 
- **`data.txt`** — same info but more readable for organization

## Tabs

1. **Petal Stats** — every petal at every tier with the in-game icon and tooltip. Search, pick a rarity, hover for the full tooltip.
2. **Mob Stats** — every mob with their stats. (currently lacking per-mob statistics)
3. **DPS Calculator** — equip 10 petals, pick a mob, then simulate your dps on it. It assumes that the server has no lag, and mob and your position is fixed.
